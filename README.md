# 강의슬라이드

강의 자료용 가벼운 슬라이드 편집기. **HTML 파일 하나**라서 설치 없이 Chrome/Edge에서 더블클릭하면 열립니다.

## 기능
- 화면 캡처 버튼 / Ctrl+V 붙여넣기
- 직사각·둥근사각·형광·원·직선·화살표·번호·글자·모자이크(블러)·펜, 스타일을 즐겨찾기로 저장 (숫자키 1~9)
- 여러 개 선택·그룹·정렬/간격/크기 맞춤(아이콘), 회전, 맨 앞/뒤, 잠금, 스타일 복사·붙여넣기, 정렬 가이드(스냅), 확대/이동, 번호 자동 재정렬
- 글자 꾸미기(굵게·기울임·밑줄·취소선·정렬·글꼴·줄간격·외곽선·그림자), 이미지 꾸미기(테두리·둥근 모서리·그림자·투명도·반전)와 자르기
- 화면비 16:9 / 4:3, 마스터 슬라이드(배경색·배경 이미지·로고·쪽번호 `{n}` `{total}`)
- PDF 가져오기(페이지를 슬라이드로, 그 위에 주석), 인쇄/PDF 저장(슬라이드만 · 슬라이드+메모)
- 프로젝트 파일(`.lecture`)로 저장하고 나중에 다시 편집
- Claude/Gemini가 만든 HTML 슬라이드 가져오기 (글자 수정 + 위에 필기)
- 발표 모드: 펜·형광펜·도형·레이저, 발표자 화면 + 청중 창(프로젝터/Zoom)

## 사용
`강의슬라이드.html`을 Chrome 또는 Edge(104 이상)로 엽니다. 단축키는 화면 위의 「단축키」 버튼.

## 개발
소스는 `src/` (head.html: 화면/스타일, editor.js: 편집, present.js: 가져오기·캡처·발표).
수정 후 `./build.sh` 로 `강의슬라이드.html`을 다시 만듭니다.
