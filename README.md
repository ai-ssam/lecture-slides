# 강의슬라이드

강의 자료용 가벼운 슬라이드 편집기. **HTML 파일 하나**라서 설치 없이 Chrome/Edge에서 더블클릭하면 열립니다.

## 기능
- 화면 캡처 버튼 / Ctrl+V 붙여넣기
- 사각형·원·화살표·번호·글자·모자이크(블러)·펜, 스타일을 즐겨찾기로 저장 (숫자키 1~9)
- 프로젝트 파일(`.lecture`)로 저장하고 나중에 다시 편집
- Claude/Gemini가 만든 HTML 슬라이드 가져오기 (글자 수정 + 위에 필기)
- 발표 모드: 펜·형광펜·도형·레이저, 발표자 화면 + 청중 창(프로젝터/Zoom)

## 사용
`강의슬라이드.html`을 Chrome 또는 Edge로 엽니다. 단축키는 화면 위의 「단축키」 버튼.

## 개발
소스는 `src/` (head.html: 화면/스타일, editor.js: 편집, present.js: 가져오기·캡처·발표).
수정 후 `./build.sh` 로 `강의슬라이드.html`을 다시 만듭니다.
